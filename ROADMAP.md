# Roadmap

Public roadmap. Want something? Open a feature request — upvotes (👍) decide priority.

## ✅ 0.1 — Foundations
- Chat, `/model` switching, 10 providers + custom servers
- Keychain key storage, cost meter, daily budgets, usage history
- Compare mode, fallback, `ask` with pipes, doctor

## 🔜 0.2 — Everyday comfort
- [ ] `winget`, Scoop and Homebrew packages
- [x] Saved prompt shortcuts: `kunji @commit`, `@explain`, `@translate`
- [x] Attach text files: `/file path` (images later)
- [x] Conversation history: list, resume and search past chats
- [x] Interactive home menu
- [ ] `/copy` last answer to clipboard
- [ ] Light-terminal theme and `display.theme` setting

## 🔭 0.3 — Power features
- [ ] Interactive full-screen form for `keys add` and settings
- [ ] Side-by-side compare columns on wide terminals
- [ ] Model aliases (`fast`, `smart`, `cheap`) you define once
- [ ] Shell mode: describe a command, review it, run it
- [ ] Plugin hooks for custom providers

## ☁️ 1.0 — kunji Pro (optional, paid)
Cloud features that need a server. Everything local stays free.
- [ ] Sync settings, prompts and history across devices (end-to-end encrypted)
- [ ] Teams: shared provider keys with per-person budgets and audit log
- [ ] Smart router: picks the cheapest model good enough for each prompt
- [ ] Usage dashboard on the web
