Your keys. Every AI model. One terminal.

kunji is a free, open-source chat app for your terminal. Bring your own API key from any provider, switch models mid-conversation, and see what every reply costs.

pipx install kunji

No Python on Windows? Download kunji.exe

Made for people who use more than one model

You already pay OpenAI, Anthropic or Google directly. kunji puts all of them behind one clean prompt, and keeps you in control of the bill.

Switch models without losing the thread
Type /model groq:llama-3.3-70b-versatile and keep talking. The conversation carries over.
See the cost of every reply
Tokens and price under each answer, /cost for the session, kunji usage for the week. Shown in your currency, including ₹.
Daily budgets
Set a limit per provider or overall. kunji warns at 80% and stops at 100%, so a long night never turns into a surprise bill.
Compare models side by side
kunji compare "…" sends one prompt to several models at once and shows which was fastest and cheapest.
Automatic fallback
When a provider is rate-limited or down, kunji retries on the next model you picked.
Works with pipes
npm test 2>&1 | kunji ask "why does this fail?" sends any command's output straight to a model.

Ten providers, plus any compatible server

Run local models with Ollama for free, or add LM Studio, vLLM or your own proxy with one command.

OpenAI, Anthropic, Google Gemini, Groq, OpenRouter, DeepSeek, Mistral, xAI, Together AI, Ollama and your own OpenAI-compatible server.

Your keys never leave your machine

Keys are stored in Windows Credential Manager, macOS Keychain or Linux Secret Service, never in a text file. Your prompts go straight to the provider you chose. kunji has no server in between.

Start in a minute

Needs Python 3.11 or newer. On Windows you can use the standalone kunji.exe instead.

  1. Install

    pipx keeps kunji in its own space, so it never clashes with your other tools.

    pipx install kunji

  2. Add a key

    Pick a provider, paste your key. kunji checks it works before saving it.

    kunji keys add

  3. Chat

    Type / to see every command, ctrl+d to quit.

    kunji

Kunji (कुंजी) means “key” in Hindi. Free and open source under Apache-2.0.
