Privacy policy

Last updated: 3 November 2026

In short: kunji has no account, no analytics and no server in the middle. Your API keys stay in your computer's keychain, and your prompts go only to the AI provider you choose.

Who this covers

This policy covers the kunji command-line app (“the app”) and this website (testwithsuraj.github.io/kunji). kunji is an open-source project; you can check everything described here in the source code.

What the app stores on your computer

  • API keys — in your operating system's credential store (Windows Credential Manager, macOS Keychain or Linux Secret Service), or read from environment variables you set. They are never written to a kunji file.
  • Settings, usage and cost history, chat input history — in your user folders. Run kunji config path to see where, and delete them any time.
  • A random install ID — a random number created on first use. It is not based on your hardware, name or account.

What the app sends, and to whom

  • To the AI provider you choose (for example OpenAI, Anthropic, Google or Groq): your messages and that provider's API key, so it can answer. That provider's own privacy policy and terms apply to what you send them.
  • To PyPI, at most once a day: a request for the latest kunji version number. Nothing about you is included. Turn off with kunji config set updates.check false.
  • To OpenRouter and GitHub, at most once a day: a download of public model price lists for the cost meter. Nothing about you is included. Turn off with kunji config set network.catalog false.
  • To kunji servers: nothing, unless you set up a kunji cloud account in a future version. If that feature is added, this policy will be updated first and it will be off by default.

The app never sends your API keys, prompts, answers, files or usage history to the kunji project.

This website

  • No cookies, no analytics, no ads, no tracking pixels. Fonts are served from this site, not a font service.
  • The home page asks GitHub for the project's star count and PyPI for the latest version number, directly from your browser. Those services receive a normal web request (such as your IP address), as described in their own privacy policies.
  • The site is hosted on GitHub Pages. GitHub may log visits for security and operations; see GitHub's privacy statement.

Children

kunji is a developer tool and is not directed at children. We do not knowingly collect information from anyone.

Changes

When this policy changes, the date at the top changes and the update is listed in the changelog.

Contact

Questions about privacy: open an issue on GitHub. To report a security problem privately, use private vulnerability reporting.

Kunji (कुंजी) means “key” in Hindi. Made in India, open source under Apache-2.0.
