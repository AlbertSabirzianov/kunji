हर मॉडल, एक जगह

दस प्रोवाइडर पहले से जुड़े हैं, और कोई भी OpenAI-compatible सर्वर भी चलता है। Key एक बार जोड़िए, kunji सेव करने से पहले उसे जाँच लेता है।

  • OpenAI, Anthropic, Google Gemini, Groq, OpenRouter, DeepSeek, Mistral, xAI, Together AI, Ollama
  • kunji providers add से LM Studio, vLLM, LiteLLM या अपना कंपनी प्रॉक्सी
  • हर प्रोवाइडर से सीधी, ताज़ा मॉडल लिस्ट
प्रोवाइडर सेटअप गाइड (अंग्रेज़ी) 
$ kunji keys add groq
✓ Verifying with Groq  0.4s  21 models available
✓ Saving key to Windows Credential Manager  0.1s
◆ Default model (type to search) llama-3.3-70b-versatile

दोबारा शुरू किए बिना मॉडल बदलें

एक मॉडल से पूछिए, फिर दूसरे से जवाब जाँचने या सुधारने को कहिए। पूरी बातचीत साथ जाती है।

  • मॉडल नामों के लिए Tab कम्प्लीशन के साथ /model
  • हर प्रोवाइडर का अपना डिफ़ॉल्ट मॉडल, और एक मुख्य डिफ़ॉल्ट
मॉडल चुनना और बदलना 
› /model anthropic:claude-sonnet-4-5
✓ Switched to anthropic:claude-sonnet-4-5  conversation kept
› ऊपर लिखे फ़ंक्शन को रिव्यू करो

खर्च जानिए, और लिमिट लगाइए

हर जवाब अपने टोकन और कीमत दिखाता है। रोज़ का बजट 80% पर चेतावनी देता है और 100% पर रोक देता है, हर प्रोवाइडर के लिए या सबके लिए, आपकी अपनी करेंसी में।

  • चैट में /cost, हफ़्ते या महीने के लिए kunji usage
  • kunji budget set all 500, खर्च ₹, $, € या किसी भी करेंसी में

मॉडल की आमने-सामने तुलना

एक प्रॉम्प्ट कई मॉडल को एक साथ भेजिए, फिर हर जवाब देखिए और जानिए कौन सबसे तेज़ और सबसे सस्ता रहा।

  • किसी काम के लिए सबसे सस्ता पर काफ़ी अच्छा मॉडल खोजें
  • ज़रूरी जवाबों को दोबारा जाँचें
मॉडल की तुलना 
$ kunji compare "explain recursion" -m openai:gpt-4o-mini -m groq:llama-3.3-70b-versatile
✓ openai:gpt-4o-mini  1.9s · 31 tok
✓ groq:llama-3.3-70b-versatile  0.6s · 27 tok
  groq:llama-3.3-70b   0.6s   fastest cheapest

रोज़ के काम के लिए सेव किए प्रॉम्प्ट

अक्सर इस्तेमाल होने वाले निर्देश, एक शब्द में। छह पहले से मौजूद हैं, और आप अपने भी सादी Markdown फ़ाइलों में लिख सकते हैं।

  • @commit आपके स्टेज किए बदलावों से commit मैसेज लिखता है
  • @explain, @review, @fix, @summarize, @translate
  • कमांड लाइन से या चैट के अंदर, दोनों जगह
सेव किए प्रॉम्प्ट 
$ git add . && kunji @commit
  Add password reset by email

  Users can now request a reset link from the
  login page. Links expire after 30 minutes.

पुरानी चैट फिर से खोलें

हर बातचीत आपके कंप्यूटर पर सेव होती है। कल वहीं से शुरू कीजिए जहाँ छोड़ा था, या पुराने जवाब खोजिए।

  • kunji chat -c आख़िरी चैट जारी रखता है
  • kunji history search docker पुरानी चैट ढूँढता है
  • कोई भी चैट Markdown में एक्सपोर्ट करें

फ़ाइल और पाइप

कोड और लॉग अटैच कीजिए, या किसी भी कमांड का आउटपुट सीधे मॉडल को भेजिए। स्क्रिप्ट के लिए सादा आउटपुट भी।

  • चैट में /file app.py, पाथ कम्प्लीशन के साथ
  • kunji ask -f app.py "what does this do?"
  • स्क्रिप्ट और CI के लिए --raw आउटपुट
पाइप और स्क्रिप्ट 
$ npm test 2>&1 | kunji ask "why does this fail?"
  The test expects a 200 but the route returns 302
  because the session cookie isn't set in the test…

कमांड टाइप नहीं करना? मेन्यू है

मुफ़्त लोकल मॉडल

Ollama के साथ मॉडल आपके अपने कंप्यूटर पर चलते हैं: न key, न बिल, और इंटरनेट के बिना भी। एक ही चैट में लोकल और क्लाउड मॉडल मिलाइए।

Ollama के साथ मुफ़्त लोकल मॉडल 
$ ollama pull llama3.2
$ kunji keys add ollama
$ kunji chat -m ollama:llama3.2

शुरू से प्राइवेट

Key आपके OS keychain में रहती है और सिर्फ़ अपने प्रोवाइडर तक जाती है। प्रॉम्प्ट सीधे आपके चुने प्रोवाइडर तक जाते हैं। न kunji का सर्वर, न अकाउंट, न एनालिटिक्स।

  • Key हमेशा छिपी (masked) दिखती है और एरर मैसेज से हटा दी जाती है
  • चैट, प्रॉम्प्ट और इस्तेमाल आपके कंप्यूटर पर ही रहते हैं
  • Apache-2.0 के तहत ओपन सोर्स, कोई भी जाँच सकता है
