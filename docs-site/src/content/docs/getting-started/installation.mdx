One command installs kunji on Windows, macOS and Linux. You don't need Python: the installer
sets everything up and adds `kunji` to your PATH, so it works in any folder.

## Install

<Tabs syncKey="os">
  <TabItem label="Windows">
    Open **PowerShell** (or **Windows Terminal**) and run:

    ```powershell
    irm https://kunji.iamsuraj.me/install.ps1 | iex
    ```

    In **Command Prompt**, run this instead:

    ```bash
    powershell -ExecutionPolicy ByPass -c "irm https://kunji.iamsuraj.me/install.ps1 | iex"
    ```
  </TabItem>
  <TabItem label="macOS">
    Open **Terminal** and run:

    ```bash
    curl -fsSL https://kunji.iamsuraj.me/install.sh | sh
    ```
  </TabItem>
  <TabItem label="Linux">
    ```bash
    curl -fsSL https://kunji.iamsuraj.me/install.sh | sh
    ```

    No `curl`? Use `wget -qO- https://kunji.iamsuraj.me/install.sh | sh`.
  </TabItem>
</Tabs>

Then open a **new terminal** and check it worked:

```bash
kunji --version
```

The command is lowercase: `kunji`.

### What the installer does

<Steps>
1. Installs [uv](https://docs.astral.sh/uv/), a small, fast tool that manages Python apps,
   if you don't have it yet.
2. Runs `uv tool install kunji`. If you don't have Python 3.11 or newer, uv downloads a
   private copy just for kunji. Your own Python, if you have one, is not touched.
3. Adds the folder with the `kunji` command to your PATH.
</Steps>

Running the installer again updates kunji. You can read the scripts first:
[install.sh](https://github.com/testwithsuraj/kunji/blob/main/install.sh) and
[install.ps1](https://github.com/testwithsuraj/kunji/blob/main/install.ps1).

Options, set before running the command:

| Variable | What it does |
| --- | --- |
| `KUNJI_VERSION=0.1.3` | Install that version instead of the newest |
| `KUNJI_NO_MODIFY_PATH=1` | Don't change your PATH |

## Other ways to install

### Already use uv or pipx?

```bash
uv tool install kunji
# or
pipx install kunji
```

### With pip

Needs Python 3.11 or newer.

```bash
python -m pip install kunji
```

On Windows, `py -m pip install kunji` also works; on macOS and Linux, use `python3`.

:::caution[“kunji” is not recognized after pip?]
pip often installs the `kunji` command into a folder that isn't on your PATH. Use the
one-line installer above instead, or run kunji through Python, which always works:

```bash
python -m kunji
```

See [Troubleshooting](/docs/help/troubleshooting/) for more.
:::

### Single file, no install

Download **kunji-windows-x64.exe** or **kunji-linux-x64** from the
[latest release](https://github.com/testwithsuraj/kunji/releases/latest) and run it from a
terminal in the folder where you saved it. On Linux, run `chmod +x kunji-linux-x64` first.

## Check your setup

```bash
kunji doctor
```

`doctor` checks your Python version, that kunji can save settings, that your OS keychain
works, and which providers you've added.

## Upgrade or uninstall

```bash
kunji upgrade                    # newest version
```

To remove kunji:

| Installed with | Uninstall |
| --- | --- |
| The installer, or uv | `uv tool uninstall kunji` |
| pipx | `pipx uninstall kunji` |
| pip | `python -m pip uninstall kunji` |
| Single file | Delete the file |

Before uninstalling, you can delete your saved keys with `kunji keys remove <provider>`.
More in [Upgrade kunji](/docs/guides/upgrading/).
